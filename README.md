**Automatic YouTube ad skipper and muter for Chrome.**

YT Ad Mute & Skip watches the page in the background. The moment an ad appears, it instantly mutes the audio, skips the ad as soon as the button is available, and restores your original volume—no clicking required.

## 📥 Installation

This extension isn't on the Chrome Web Store, so it is installed manually in 3 quick steps:

### Step 1 — Download the ZIP
👉 [**Download YT-Ad-Mute-Skip-v2.zip**](https://github.com/harivishnu9345-creator/youtube-ad-skip/releases/download/v2.0.0/YT-Ad-Mute-Skip-v2.zip)

Then unzip the folder anywhere on your computer.

### Step 2 — Open Chrome's Extensions page
In Chrome, go to:
chrome://extensions

Turn on **Developer mode** using the toggle in the top-right corner of the page.

### Step 3 — Load the extension
Click **Load unpacked**, then select the unzipped youtube-ad-skip folder.

That's it — the extension icon will appear in your toolbar. Pin it for easy access, and use the on/off switch in the popup whenever you want to pause it.

---

## ⚙️ Usage

Click the extension icon in your toolbar to open the popup. The switch is **ON by default** — flip it off any time to disable the ad-skipping behavior without removing the extension.

The popup also shows a small dashboard:
- **Skipped this tab** — resets each time you open a fresh YouTube tab
- **Total ads skipped** — an all-time running total that persists across browser restarts
